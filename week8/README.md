# Handwritten Digit Recognizer (MNIST)

## Project Overview

This project was completed as part of my EDP Internship. The project focuses on recognizing handwritten digits from 0 to 9 using the MNIST dataset.

The project covers image preprocessing, normalization, KNN classification, neural networks, model evaluation, accuracy improvement, confusion matrix analysis, and visualization.

## Objectives

- Understand image data preprocessing
- Normalize MNIST image data
- Train a KNN baseline model
- Train a Neural Network model
- Improve model accuracy
- Analyze misclassified digits
- Visualize model performance
- Document the Machine Learning project

## Dataset

The MNIST dataset contains handwritten digit images representing digits from 0 to 9.

Each image is:

- 28 × 28 pixels
- Grayscale
- Represents one digit from 0 to 9

## Machine Learning Models

### K-Nearest Neighbors (KNN)

KNN was used as a baseline model for handwritten digit classification.

**Accuracy: 94.63%**

### Neural Network

A Neural Network was trained to improve the classification performance.

**Improved Accuracy: 98.02%**

## Model Evaluation

The models were evaluated using:

- Accuracy
- Confusion Matrix
